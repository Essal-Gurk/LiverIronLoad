# Ready-to-install ARM64 release

Download `Liver-IronLoad-v0.8-arm64.zip`, extract it, quit IsiX and run `bash install.sh` from the extracted folder. Requires macOS 15+ and IsiX 6.0.8+. The bundle is ad hoc signed and is not Apple-notarized.

The ZIP is the previously prepared v0.8 binary, unchanged. Source and documentation are available at the repository root. Clinical validation and regulatory status are described in the main README and `Docs/EU_MEDICAL_USE.md`.
